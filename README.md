# Computación Científica - Maestría en Física UAS
En este repositorio se encuentra el proyecto del estudiante de la maestría en física Eduardo Tirado Félix, el cual es un estudio del dengue/chikungunya en México en el 2024.

Base de datos epidemiológicos del gobierno federal de México:
https://www.gob.mx/salud/documentos/datos-abiertos-152127

Funciones y modelos basados y/o usados en la realizción de este proyecto:
